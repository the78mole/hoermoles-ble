Hoermoles

Independent control of Hörmann garage door drives using the BlueSecur BLE "Signed" protocol - without the vendor app and without the cloud.

  • Open the web app → Control a drive over Web Bluetooth. Installable to the home screen and fully offline-capable. Needs Chrome or Edge - Safari and Firefox have no Web Bluetooth.
  • Source, CLI and protocol notes → The Python library and CLI, the reverse-engineered protocol documentation, and how to move credentials between them and the web app.
